# LLM Quality Survey

Working repository for:

**Towards End-to-End Quality Assessment of LLM-Based Systems: A Survey of Quality Dimensions, Evaluation Methods, and Integration**

## Structure

- `main.tex`: ACM journal entry point
- `sections/`: article sections
- `references.bib`: verified bibliography only
- `figures/`: final taxonomy, review flow, and quantitative figures

## Current status

The repository contains the first writing pass for the Introduction, Background and Scope, Research Questions, Review Methodology, and the conceptual taxonomy. Quantitative results, final corpus counts, references, and gap synthesis remain intentionally open until the peer-review audit and classification validation are complete.
